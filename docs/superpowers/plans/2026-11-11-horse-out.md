# The horse goes out (farm economy v2, part 5): plan, 11 Nov 2026

Owner's rules: docs/farm-economy-v2.md section 6. Branch feat/horse-out (from feat/raid-badge @3af123b).

## Files
- `src/00-zzzzzzzzzzzzzzzzzzz-horse.js` (content): `C.HORSE_OUT`, every number in one block (the ones the doc does
  not give are marked "decided by me, owner can change"); the 3 gear icons appended to `C.ICON_ORDER`.
- `src/01-logicZZZZZZZZZZZZZZ-horse.js` (rules): hearts on a 10-heart scale (love / 10), the zone of a map (farm, town,
  wild, hunt, cave), may the horse be ridden there (hearts, Horseshoes, Lantern Bridle), stamina (drain a tile, food,
  full at the new day), feeding, making gear at the Stable, the knock-off roll, the save (`hs` gets 3 more numbers;
  an old save's horse gets at least 3 hearts once, so town riding stays open), the Saddlebags hook for part 3.
- `src/19-extras.js`: the fixed `RIDE_MAPS` checks go through two methods (`horseMapOk`, `horseSpot`) so a later
  file can widen them.
- `src/19zzzzzzzzzzzzzzzzzzzzzzzzz-horse-out.js` (world): riding out there, the stamina bar, tired = you get off and it
  follows you, feeding, shooting from the saddle, the knock-off in caves (it runs to the entrance and waits), the
  Stable panel (hearts, stamina, gear), the first-ride tip.
- Online: `src/19h-online.js` keeps others' `rd` on every map a horse may go; `src/19zzzzzzzzz-gameserver.js` reads
  `rd` from a room's look (`lk`) and sends a new look on mount/dismount. The server already passes `lk.rd` on: no
  server change.
- Art: `tools/art/economy-import.js` cuts economy-2 cells 1-3 (horseshoes, saddlebags, lantern_bridle) once they
  have icon slots.

## Tests
