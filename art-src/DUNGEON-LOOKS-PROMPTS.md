# Harvest Ville: the five dungeon looks (owner, 8 Nov 2026)

One costume for each hunting place's cave, like the Fire look from Bakunawa's Lair: never sold in Tita Luz's shop. A
1 in 10 chance each time you help beat that cave's floor-50 boss, or Kanor makes it from the cave's parts and a lot of
Gold. Each look is 6 pictures, made exactly like the Fire look and the 8 shop looks: a real image EDIT of the farmer's
own sheets, so every pose stays where it is.

HOW TO MAKE THEM
1. Attach the EDIT TARGET from `targets/` in this kit (boy-walk.png, girl-walk.png, boy-tools.png, girl-tools.png,
   boy-archer.png, girl-archer.png): the same six used for the Fire look.
2. Do the two WALK pictures of a look first and check them. The tools and archer pictures then copy the outfit from the
   approved walk picture (attach it as the second image).
3. Save each with the file name shown and send them in a zip, like before. The names are all that matter.
4. If the background comes out see-through or white instead of magenta, that is okay too.
