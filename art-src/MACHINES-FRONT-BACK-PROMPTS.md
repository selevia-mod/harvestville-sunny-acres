## How to make each picture
Attach TWO pictures from the `attach` folder, then paste CAMERA, then the machine's ONE view line below.
- **Image 1** = `image1_camera_30deg_farmer.png` (always the same: it shows the camera height).
- **Image 2** = `image2_side_<machine>.png` (your own side picture: it keeps the same machine, colors and details).

### CAMERA (paste first, every time)
```

The camera is only a LITTLE above, looking down at about 30 degrees: exactly the same camera height as the farmer in Image 1 (use Image 1 ONLY for the camera height; do not draw the farmer). Draw the SAME machine as Image 2, with the same shape, colors, paint, wheels and details, the same size (use Image 2 ONLY for the design; it is a side view, do not copy its angle). NO driver and nobody on it: the seat is empty and can be seen. Nothing is bent, curved or fish-eyed: straight lines stay straight. The view is perfectly symmetrical left to right. No text, no letters, no numbers, no logos, no watermark, no border, no drop shadow box, no ground, no dust. One single game prop, isolated on a fully transparent background (PNG with alpha). If transparency is not possible, use a flat solid pure magenta #FF00FF background with nothing else on it. Keep the whole machine inside the picture with some empty margin, its wheels along the bottom of the picture.
```
