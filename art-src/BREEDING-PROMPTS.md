# Harvest Ville: animal breeds (owner, 4 Nov 2026: "animal breeds and colours, and rare ones to collect")

Why: every farm animal now comes in a few colours (src/00-zzzzzzz-breeding.js). Until these pictures come, the game paints
them at runtime from the animal's own frames (src/19zz-breeding.js): good enough to play, but a real picture can give a
breed its own markings (the Highland Cow's shaggy coat, sparkles on the rare ones) that a recolour cannot.

Every picture: **1024x1536 (tall)**, the same 3 x 4 grid of poses as `farm_chicken.png` / `farm_cow.png` / `farm_pig.png`
/ `farm_carabao.png` (ANIMALS-3Q-PROMPTS.md), so the import cuts them the same way (tools/art/animals3q-import.js) into a
new row of 12 frames each. Save each with the file name shown. The rare ones (marked RARE) first.

When they are in: give each breed in C.BREEDS its sheet row (e.g. `frame0`) and let F.Breeds.texture use that row instead
of painting (the recolour stays the fallback for any breed without a picture).
