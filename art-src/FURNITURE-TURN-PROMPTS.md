# Turning furniture: side and back views (owner, 8 Nov 2026: "Furniture should be turned not just flip" ... "lets
generate new art")

Today a piece only flips left and right. With these, beds, double beds, chairs, armchairs, sofas and tables turn four
ways: front (the pictures we have), side (facing left; facing right is the same picture mirrored, which is correct for
a side view) and back. One picture per style, 10 in all, a 4 x 3 grid. Transparent background (or flat magenta
#FF00FF). Save each in `art-src/furniture/` with the file name shown, and send them.

Each piece must match its style's front picture we already have (`art-src/furniture/<style>_a.png`): same piece, same
colours, same size, only turned. Tip: attach that style's front picture to the image tool as a reference when you
generate, so the turned pieces match it.
