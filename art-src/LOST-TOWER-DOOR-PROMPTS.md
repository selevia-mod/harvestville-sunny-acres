# The Lost Tower: the 10 doors up (owner, 12 Nov 2026, second try)

The first stairs pictures looked like a hatch in the FLOOR going down. The way up is now a **door in the back wall** of each
floor, and you walk through it to climb up. `PLACEMENT-door-in-wall.png` shows where it stands in the game (that one is only my
drawn stand-in: the shape and the place, not the look).

**How:** one prompt = one picture, each in a NEW chat. Attach **`CAMERA-30deg-farmer.png` as Image 1** (only for the camera
height) and **`PLACEMENT-door-in-wall.png` as Image 2** (only for where the door stands and its shape). Save each with the
file name shown, e.g. `tower/zone1/door.png`, and send them as a zip like before.

Each picture: 1536 x 1024, two doors side by side (left SHUT, right OPEN), transparent background.
