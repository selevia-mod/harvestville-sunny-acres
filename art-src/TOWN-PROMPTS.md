# Town art: prompts

Generate each picture and save it under `art-src/` with the file name shown (in that folder), then send them to me.

Tips:
- Characters: 3 columns x 3 rows, same as the villagers you made before (row 1 facing the camera, row 2 facing away, row 3 facing left; columns: standing, left step, right step), on a transparent or plain magenta background.
- Buildings: seen from the front, door in the middle at the bottom.
- The sand is a seamless square texture.
