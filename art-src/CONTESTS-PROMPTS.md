# Harvest Ville: festival contests (4 Nov 2026)

The contests (src/19zz-contests.js) draw their ribbons and the trophy cup at runtime for now. When these pictures come,
save them in art-src/contests/ and the game can show them in place of the drawn ones (the judging card, the prize card,
Collection > Ribbons and the tour). They are not item icons: the items sheet is full, so they stay separate pictures.

One prompt for all 5 pictures.

```

If transparency is not possible, use a flat solid pure magenta #FF00FF background with nothing else on it. Keep the whole object inside the picture with some empty margin.

PICTURE 1, named ribbon_blue.png, 512x640 tall: One single prize rosette ribbon for a country fair, filling most of the picture: a round pleated rosette in royal blue with a plain round cream centre (left empty, no number), and two blue ribbon tails hanging down with notched ends. A tiny gold rim around the centre.

PICTURE 2, named ribbon_red.png, 512x640 tall: The same prize rosette ribbon as picture 1, in exactly the same shape, size and pose, but in warm cherry red, with a plain round cream centre (left empty, no number) and two red ribbon tails with notched ends.

PICTURE 3, named ribbon_yellow.png, 512x640 tall: The same prize rosette ribbon as picture 1, in exactly the same shape, size and pose, but in sunny golden yellow, with a plain round cream centre (left empty, no number) and two yellow ribbon tails with notched ends.

PICTURE 4, named ribbon_green.png, 512x640 tall: The same prize rosette ribbon as picture 1, in exactly the same shape, size and pose, but in soft leaf green, smaller pleats, with a plain round cream centre (left empty, no number): a thank-you ribbon for taking part.
```
