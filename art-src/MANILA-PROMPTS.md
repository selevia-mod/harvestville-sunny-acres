# Manila: the art (proposed, 11 Nov 2026)

Every picture Manila needs: the city, its people, the three hunting grounds and their caves, the three new weapons at every level, and the icons. 116 pictures in 7 batches. Until a picture comes the game uses a drawn stand-in, so they can be made in any order, a batch at a time. The plan they belong to is docs/manila-proposals.md (names and numbers there are proposals: if the owner changes one, the prompt changes with it).

All of it goes in a DOWNLOAD PACK (the game page is nearly full): nothing here is built into the page.

Save each with the file name shown, in the folder shown (art-src/<folder>/...). Send them in zips like before: the names are all that matter.

Tips: 1024x1536 is tall, 1536x1024 is wide, the rest are square 1024x1024. If the background comes out magenta instead of see-through, that's okay. Creatures use the same 12-pose sheet as the places and the Lair (3 directions: front, back, left; the game mirrors left for right; row 4 = three extra poses). Ground, water and cave textures must tile without a seam. People use the villagers' 3 x 3 walking sheet. No real company names, logos, flags or official seals anywhere: real Manila is only a cozy cartoon inspiration.
