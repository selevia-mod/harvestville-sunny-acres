# Harvest Ville: places 1-5 + Central Park art (owner, 6 Nov 2026)

Every picture for the first five new hunting places, their dungeons, Kanor's Jeep, the medals and Central Park's Hall of Fame. Until they come the game uses drawn stand-ins, so they can be made a few at a time, in any order. Save each with the file name shown, in the folder shown (art-src/<folder>/...). Send them in zips like before: the names are all that matter.

Tips: 1024x1536 is tall, 1536x1024 is wide, the rest are square 1024x1024. If the background comes out magenta instead of see-through, that's okay. Creatures use the same 12-pose sheet as the Wild Lands and the Lair (see targets/style-creature-*.png). The cave textures and ground textures must tile without a seam.
